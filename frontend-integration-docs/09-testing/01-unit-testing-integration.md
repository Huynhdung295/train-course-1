# Tích hợp Unit Testing

## 1. Khái niệm (Backend)
Backend test các logic siêu nhỏ gọn độc lập (như tính tiền, kiểm tra format) không cần Database.

## 2. Tích hợp React (Best Practices)
- Frontend cũng cần Unit Test bằng `Jest` hoặc `Vitest` cho các hàm tính toán, helper function, hoặc format tiền tệ.
