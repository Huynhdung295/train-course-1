# Tích hợp Performance Testing

## 1. Khái niệm (Backend)
Dùng K6.js hoặc JMeter để bắn hàng ngàn request kiểm tra sức chịu đựng của API.

## 2. Tích hợp React (Best Practices)
- Hiệu năng Frontend cũng quan trọng không kém (Lighthouse score).
- Đảm bảo Code Splitting, Lazy load components, nén ảnh (WebP) để ứng dụng tải nhanh trước khi Backend kịp trả dữ liệu.
